# homebrew-lumen

The Homebrew tap for Lumen, the UI framework.

```
brew tap lumen-fx/lumen
brew install lumen
```

That installs `lumenc` and the Lumen runtime library from the latest release of
[lumen-fx/lumen](https://github.com/lumen-fx/lumen).

`Formula/lumen.rb` is written by the release workflow in the Lumen repository
and points at the release archives; edit it there, not here.
